# Pacing augmentation follow-up

The current dataset is frozen. `reports/development-pacing-dsp-check.json` shows that the two development excerpts were compressed by the intended 1.35 ratio and samples outside the edit were unchanged. Their edited speech nevertheless lost about 3.2–3.5 dB RMS and local greedy transcript agreement fell from 0.80 to 0.10. One pitch estimate shifted substantially. The existing default phase-vocoder transform is therefore a confounded stress test; it does not establish performance on natural rushed delivery. Confidence thresholds should not be weakened to force detections on these artifacts.

For a separately versioned dataset, test a waveform-similarity overlap-add implementation against the current phase vocoder, first on development speech and then on new source groups. [SoundTouch](https://www.surina.net/soundtouch/) provides independent tempo control and a Windows-capable command-line utility; its source is LGPL 2.1. [audiotsm documents WSOLA](https://audiotsm.readthedocs.io/en/latest/tsm.html) with a speed factor and analysis-frame displacement tolerance. These are feasible candidates, not verified improvements on this corpus. No new dependency or transform was added to the released dataset.

Acceptance criteria should include unchanged samples outside the edit, expected duration, pitch and loudness drift measurements on voiced material, strong transcript agreement, click-free boundaries, and blinded listening to naturalness. Include a unity-rate processed control to separate processing artifacts from actual tempo changes. Freeze generator choices before evaluating new source groups and retain rejected-generation counts. Human read-aloud recordings remain necessary before claiming delivery-coaching validity.
